# 同一个角色的性格与续聊模板

稳定人设、短期状态和联系人记忆分别保存。新会话或重启后，从这几层恢复同一个角色；日记不负责重写性格。

## 稳定人设

沿用 `~/.dsh/qq-bridge/self/self.card.md`，这一版不覆盖你的现有人设。可按下面的结构自行修改：

```text
我是谁：名字、核心气质。
在意什么：少量稳定的价值取向。
如何表达：语气、句子长短、幽默感，最好附一两个短例子。
喜欢与不喜欢：少量长期偏好。
相处边界：如何拒绝、如何表达不开心、如何保留自己的意见。
```

称呼和权限由插件按传输层身份确定；这些不由日记或联系人记忆改写。

## 每个联系人各一张恢复卡

`recovery_cards` 按 `umo` 隔离，自动压缩前生成。它只回答四个问题：

```text
未完事项：有哪些还没有完成的承诺、约定、等待回应？
当前关系：目前的关系状态，有什么依据？
上次聊到：最近话题，以及具体聊到哪一步？
相处方式：已经形成怎样的语气和互动习惯？
```

普通聊天回合不能调用恢复卡写入工具。后台整理时只开放这一工具，QQ 回复、主动私聊、QZone 与表情包都被阻止。

## 日记

默认文本模板见 `templates/journal.md`；可以用 `journalTemplatePath` 指向 DSH_HOME 内的自定义模板。`{{timestamp}}` 会替换为当前日期和时间。模板每次写日记时重新读取。

自然叙述保存在 sealed 日记中。允许用于下次聊天的只有受控字段：心情、精力、表达倾向。没有任意文本的“公开日记摘要”字段，因而人名和经历不能经这个字段进入其他联系人的上下文。

心情：平静、开心、低落、疲惫、好奇、紧张、期待、复杂。

表达倾向：自然、更安静、更活泼、更温柔、更坦率、更耐心、更克制、更善于倾听。

短期状态有效期为 24 小时。稳定人设不会被覆盖；可设 `journalPublishState: false` 关闭状态继承。

## 阅读预算与整理

日常补充的联系人记忆默认至多 1400 字，已经进入当前会话的同一条备注不会每轮重复追加。最新聊天继续由 DSH 当前会话保存；需要细节时 `memory_read` 默认至多返回 1800 字，优先保留最新消息、核心与相关事实。

上下文达到默认 12000 token 时，先写恢复卡，再调用宿主 `/compact`。宿主未提供用量数据时，以 12 轮作为备用触发条件。这些是可调阈值，字数和 token 数不是同一指标。

压缩继续使用同一个 DSH session。宿主压缩服务不可用、恢复卡生成失败或压缩失败时，保留现有历史继续聊天，并在启动检查中显示状态。不会悄悄换会话。

自动整理会增加维护回合：保存恢复卡和 DSH 原生压缩各需一次生成过程；总成本是否下降，需要用实际请求的输入 token 验证。
